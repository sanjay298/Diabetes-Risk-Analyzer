# 🩺 Diabetes Risk Analyzer

## Predict, Explain, and Prevent: AI-Driven Diabetes Risk Analysis

An AI-powered healthcare application that predicts diabetes risk based on patient health indicators and provides personalized recommendations through an interactive dashboard.

## Features

* Diabetes Risk Prediction
* Risk Percentage Analysis
* Health Score Dashboard
* Personalized Health Recommendations
* PDF Report Generation
* Interactive Streamlit Interface
* Risk Categorization (Low / Moderate / High)

## Tech Stack

* Python
* Streamlit
* Scikit-Learn
* Pandas
* NumPy
* Matplotlib
* ReportLab

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
